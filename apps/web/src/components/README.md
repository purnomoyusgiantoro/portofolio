# components/

Folder ini untuk komponen React lokal yang hanya dipakai di dalam `apps/web`.

Contoh penggunaan:
- Komponen UI spesifik halaman tertentu
- Widget kecil yang belum perlu dipindah ke `packages/ui`

Untuk komponen yang dipakai di banyak tempat atau app lain,
pindahkan ke `packages/ui/src/components/`.
